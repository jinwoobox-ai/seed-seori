HACK-01 ▸대기 중
판을 보여줘

스크린샷을 붙여넣거나 화면 보기를 켜면 바로 계산할게.

설정

규칙

금지 수 없음 · 6목 이상도 승리

내 돌
계산

모든 빈자리를 계산하고, 답이 굳을 때까지 계속 깊이 읽어요 (최대 20초)

돌 위치

실시간 화면 보기

이 페이지 안에서는 화면 공유가 막혀 있어요. 아래 버튼으로 내려받아 크롬이나 엣지로 열면 게임 창을 계속 보면서 알려 줘요.

  1. 받은 오목사기꾼.html 파일을 더블클릭
  2. 화면 보기 시작 → 오목 게임 창 선택
  3. 미니창으로 HACK-01을 항상 위에

여기서는 화면 공유를 쓸 수 없어요

이 페이지는 보안 때문에 화면을 직접 볼 수 없어요. 대신 이렇게 쓰세요.

  1. 스크린샷 붙여넣기: 윈도우는 Win + Shift + S, 맥은 Cmd + Ctrl + Shift + 4로 게임 판을 찍고 이 페이지에서 Ctrl + V
  2. 실시간 버전: 파일로 내려받아 브라우저로 열면 게임 창을 계속 보면서 알려 줘요
