NEXUS 2.1.0 - Windows 포터블 빌드 안내

이 패키지는 기존 앱 기능과 소스를 변경하지 않고 Windows용 단일 포터블 EXE를 빌드하기 위한 GitHub Actions 워크플로를 포함합니다.

중요:
- 이 ZIP 자체는 아직 EXE가 아닙니다.
- 빌드는 GitHub Actions의 Windows 빌드 머신에서 수행됩니다.
- 빌드된 NEXUS-Portable-2.1.0.exe는 대상 PC에 Node.js나 NEXUS 설치 프로그램이 필요 없는 포터블 앱입니다.
- 최초 실행 시 앱 자체가 필요한 외부 서비스(Open Cloud 등) 연결을 위해 인터넷이 필요할 수 있습니다.

빌드 방법:
1. ZIP을 GitHub 저장소에 업로드하거나 새 저장소에 압축을 풀어 소스 파일을 올립니다.
2. 저장소의 Actions 탭을 엽니다.
3. 왼쪽에서 'Build NEXUS Windows Portable'을 선택합니다.
4. 'Run workflow'를 누릅니다.
5. 작업이 성공하면 실행 결과 페이지의 Artifacts에서 'NEXUS-Windows-Portable-2.1.0'을 다운로드합니다.
6. 받은 artifact ZIP을 풀고 NEXUS-Portable-2.1.0.exe를 실행합니다.

보안 및 검증:
- 이 빌드 과정은 기존 앱 코드를 실행 파일로 패키징할 뿐, Roblox 클라이언트에 임의 코드를 주입하거나 Roblox 보안을 우회하는 기능을 추가하지 않습니다.
- 실제 Roblox 게임 연결 및 모든 테스트 기능은 별도 실환경 검증이 필요합니다.
